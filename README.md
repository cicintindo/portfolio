## Tecnologias

HTML5, CSS3 e JavaScript puros, com Bootstrap 5 via CDN como único framework. Ícones em SVG embutido no próprio HTML e tipografia Poppins (Google Fonts).

## Como rodar

1. Clone o repositório: `git clone https://github.com/cicintindo/portfolio.git`
2. Abra o `index.html` no navegador. É só isso — não tem build nem dependência pra instalar.
3. *Opcional:* extensão **Live Server** no VS Code, para recarregar sozinho ao salvar.

## O que tem no site

- Hero em tela cheia com foto, banner e botões de ação
- Menu fixo responsivo com rolagem suave e destaque da seção ativa
- 8 seções: apresentação, formação, competências, projetos, experiências, hobbies, viagens e contato
- Formulário com validação em JavaScript (mensagens na própria página, sem alert)
- Animações de entrada, botão "voltar ao topo" e fallback automático da foto
