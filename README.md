# Portfólio Pessoal — Cintia Kamei

Este projeto é um portfólio pessoal responsivo desenvolvido como parte da 1ª Entrega da disciplina. O objetivo principal é apresentar minha trajetória acadêmica em Análise e Desenvolvimento de Sistemas (IFSP), habilidades lógicas, histórico educacional, projetos e interesses pessoais.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização customizada em tons pastéis (rosa) e visual minimalista.
* **Bootstrap 5 (CDN):** Framework para garantida de responsividade e componentes visuais.
* **JavaScript (ES6):** Interatividade e validação do formulário de contato.

---

## 📋 Resumo das Funcionalidades
* **Navegação Fixa:** Menu superior com ancoragem para rolagem suave até cada seção.
* **Menu Responsivo:** Adaptação automática para dispositivos móveis (botão hambúrguer).
* **8 Seções Exigidas:** Apresentação Pessoal, Formação Acadêmica, Conhecimentos, Projetos, Experiências, Hobbies, Viagens e Contato.
* **Validação de Formulário:** Script JS para verificação de preenchimento dos campos de mensagem.

---

## 🚀 Como Executar o Projeto Localmente
1. Baixe ou clone este repositório para o seu computador.
2. Certifique-se de manter a estrutura de pastas (`css/`, `js/`, `assets/`, `docs/`).
3. Abra o arquivo `index.html` em qualquer navegador web atualizado.
4. *(Opcional)* Se estiver no VS Code, clique com o botão direito sobre o `index.html` e selecione **Open with Live Server**.
